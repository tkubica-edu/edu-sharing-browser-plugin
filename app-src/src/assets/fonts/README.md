# Bundled icon fonts

Downloaded from Google Fonts on 2026-09-17, preserving the three families previously
requested by `src/index.html`. Material Symbols uses opsz=24, wght=400, FILL=0, GRAD=0.
The fonts are redistributed under the included Apache 2.0 LICENSE from
https://github.com/google/material-design-icons.

Angular copies this directory to `sidebar/assets/fonts/`. `icons.css` uses only local
URLs; neither building nor displaying the icons requires network access.
